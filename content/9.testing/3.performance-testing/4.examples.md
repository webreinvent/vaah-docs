## Example 1: Load Test with Token-Based Authentication (Login + Authenticated API)
**Concepts Used:**
- Setup function
- Token-based authentication
- Custom headers
- ramping-vus executor with stages

::code-group
    ```bash [loginAuthTest.js]
    import http from 'k6/http';
    import { check, sleep } from 'k6';

    export let options = {
        scenarios: {
            auth_api_test: {
                executor: 'ramping-vus',
                startVUs: 0,
                stages: [
                    { duration: '30s', target: 20 },
                    { duration: '1m', target: 20 },
                    { duration: '30s', target: 0 },
                ],
            },
        },
    };

    export default function () {
        const loginPayload = JSON.stringify({ username: 'test', password: 'test123' });
        const loginHeaders = { 'Content-Type': 'application/json' };

        const res = http.post('https://test-api.k6.io/auth/token/login/', loginPayload, { headers: loginHeaders });
        const token = res.json('access');

        const headers = {
            Authorization: `Bearer ${token}`,
        };

        const res = http.get('https://test-api.k6.io/my/crocodiles/', { headers });

        check(res, {
            'is 200': (r) => r.status === 200,
        });

        sleep(1);
    }
::

## Example 2: Multiple Performance Testing Scenario in a Single Tests
**Concepts Used:**
- `Stages`: Each scenario uses its own set of stages to define how VUs ramp up or down over time. Load Test, Spike Test and Soak Test:
- `Executor: ramping-vus`: Simulates a realistic load pattern by gradually increasing or decreasing the number of virtual users (VUs).
- `Custom cookies`: Custom cookies can be set per request (e.g., "new-website": "true").

::code-group
    ```bash [script.js]
    import http from 'k6/http';
    import { check, sleep } from 'k6';

    export let options = {
        scenarios: {
            load_test: {                                      // Load testing scenario
                executor: 'ramping-vus',
                stages: [
                    { duration: '30s', target: 100 }, // ramp up to 100 VUs in 30 seconds
                    { duration: '5m', target: 100 },  // stay at 100 VUs for 5 minutes
                    { duration: '30s', target: 0 },   // ramp down to 0 VUs in 30 seconds
                ],
            },
            spike_test: {                                     // Spike testing scenario
                executor: 'ramping-vus',
                stages: [
                    { duration: '30s', target: 200 }, // spike up to 200 VUs in 30 seconds
                    { duration: '1m', target: 200 },  // sustain 200 VUs for 1 minute
                    { duration: '30s', target: 0 },   // drop back to 0 VUs over 30 seconds.
                ],
            },
            soak_test: {                                      // Soak testing scenario
                executor: 'ramping-vus',
                stages: [
                    { duration: '5m', target: 50 },  // 50 VUs running continuously
                ]
            }
        },
    };

    export default function () {
        const urls = 'https://test-api.k6.io/';
    
        const res = http.get(url, {
            cookies: {
                "new-website": 'true',
            },
        });

        // Log the response time
        console.log(`${page} status: ${res.status}`);
        console.log(`${page} duration: ${res.timings.duration} ms`);

        // Perform the checks
        check(res, {
            [`${page} should return a 200-299 status code`]: (r) => r.status >= 200 && r.status < 300,
            [`${page} response time should be less than 7000s`]: (r) => r.timings.duration < 7000,
        });
    }
